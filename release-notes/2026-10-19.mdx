## More item check rules

Item types can now check that one number or date field compares with another, that a date is not in the past or future, before or after a date, or within some days of today. Checks can also require text to match a pattern or a length, and require that an item has no unresolved comments.

Link checks can set a maximum, for example exactly one parent System. Flow AI can read and set up the new rules.

## Improvements & Fixes

### Agent

- **Long fields read in full.** When a question depends on an item's description or another long field, the agent reads the whole value. Answers that hinge on a clause at the end of a long description are grounded in that clause instead of a guess.
- **Explanations before pauses.** Explanations and questions no longer go missing when the agent pauses for your reply.
- **Questions with selectable answers.** A validation error no longer interrupts questions that offer choices.

### Automations

- **Item timestamps in scripts.** Scripts and branch checks can read when an item was created and last changed with `item.created_at` and `item.updated_at`. See [Automations](/api/automations/overview).

<Warning>
  If a custom field is named `created_at` or `updated_at`, read it with `item["created_at"]` or `item["updated_at"]`. Dot access now returns the item's timestamp in scripts, and `item.updated_at` raises an error in formulas.
</Warning>

### Diagrams

- **SVG images.** Add SVG files to a diagram from the image toolbar button, by dragging them onto the canvas, or by pasting them, as with PNG, JPEG, GIF, and WebP images.

### Login

- **SSO invitations** _(self-hosted)_. Private deployments using direct OIDC send invited users to their organization's sign-in flow instead of asking them to create a Flow password.
