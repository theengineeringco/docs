## Units on number fields

A number can now carry its unit, so a mass reads "12 kg" wherever the item appears. The details panel and the Reader give the unit its own box beside the value, with a dropdown that suggests common engineering units such as kg, mm, N, Pa, and °C as you type. In the table, type the unit straight after the number in the same cell. A unit outside the list is kept exactly as entered.

Filters, sorting, and roll-ups keep working on the number itself, so a unit never changes what a total or a comparison means. Units travel with the value across the table, tree nodes, the Reader and its exports, review diff cards, item history, and copy and paste between cells. When you create an item, editing the number or its unit preserves the other, including after you reopen a draft or reload the page.

## Self-hosted email through your own mail server

Self-hosted deployments can send notification and email MFA messages through an SMTP relay they run, such as Exchange, Postfix, or Microsoft 365, instead of only Amazon SES. Email stays off until configured.

## Improvements & Fixes

### Agent

- **More places to open the AI agent.** Open the AI agent panel alongside the Automations and Skills libraries and the Activity feed to get help while you work in them.

### Automations

- **Automation runs in past conversations.** Past conversations in the AI window add an **Automations** list beside **Chats**, holding automations you ran yourself from an item's menu, the details panel, or a review. Select one to reopen the run. Runs started by other people, a schedule, or an integration are not listed.

### Branching

- **Creating branches.** Creating a branch in a large project with many formulas is faster and no longer fails after 30 seconds.

### Data Model

- **Pickers.** Multi-select tag, user, linked-item, and integration pickers list every selected or partly selected option first when they open, in fields, bulk edits, and filters.

### Files

- **PDF imports and previews.** Detailed drawings use less memory when opened or zoomed, and scanned tables render with their embedded images intact.

### Integrations

- **Jira issue details.** Issue previews and AI reads include the resolution and linked issues, with their Jira IDs and issue keys. Previews open linked issues directly in Jira.
- **Linear issue cards.** Linear issues the assistant creates or looks up show the same card as hovering an issue in a table, the details panel, or a review. The card now also lists priority, assignee, team, and project.

### Search

- **Search and Find in view.** Names and text containing short ranges such as `0-15` and decimal values can now be found and highlighted.

### Settings

- **Settings search.** Page-name matches appear first, followed by results within matching pages, other matching titles, and description or keyword matches.

### Views

- **View controls beside the details panel.** Share, more actions, Find in view, Display options, Sort, Filter, and active filters move to sit beside an open details panel instead of being hidden under it, and follow its edge as you resize it.

## API Changes

- **Automations.** The [Customer API](/api/automations/overview) can list, read, create, edit, and delete a project's automations. An automation runs as the person who last saved what it runs, so editing someone else's automation in a way that changes what it runs requires your explicit confirmation. Hosted MCP can list and read automations but not change them, and admin tools can't be turned on with an API key.
- **Entity filtering.** The [Customer API](/api/reference) can find items by type, field values, tags, owners, dates, or missing values, combine conditions with AND/OR, and page through results on a selected branch.
- **Restore deleted items.** The [Customer API](/api/reference) lists the items deleted on a branch, newest first, and restores one or a batch with the fields, links, and position they had when deleted.
- **Admin edits on restricted branches.** Project admins can explicitly bypass branch protection and editor groups for entity API writes without changing branch settings. Item locks and other write validation still apply.
- **Custom MCP connections.** Saved OAuth credentials are bound to their original authorization server and can't be reused with a different server. Remove and recreate an existing OAuth connection if its saved authorization-server information is missing.
