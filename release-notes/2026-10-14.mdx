## Item checks

Define the rules every item of a type should meet, in **Settings → Checks** or in the **Checks** section of each item type's page in **Settings → Data Model**. A check can require that a field is set, that a value is one of a list, that a number is within a range, that text contains or does not contain a phrase such as "TBD", or that an item has a minimum number of upstream or downstream links to chosen types.

A failing field shows a cross in its cell, and hovering it explains why, such as "Owner is empty". The details panel shows a badge such as "2 checks failed". Tables show marks once their **Show checks** display option is on. A branch review's Overview lists **Item checks** among its automations, with failures by item type and rule and a link to the failing items. Failing item checks never block approval or merging.

## Merge a branch automatically once it is ready

With **Allow automatic merging** on in **Settings → Reviews**, a branch still waiting on approvals, checks, or stage reviews offers **Merge When Ready** in its merge box. The branch then merges itself, as the person who asked, as soon as every merge requirement is met. Anyone who can merge the branch can cancel the request, and switching the setting off cancels every waiting branch.

## The assistant asks structured questions

When the agent needs a decision or a fact only you can supply, it asks with a question card instead of prose. Each question offers a few one-line choices, with the recommended one first, checkboxes where several apply, and an **Other** box for your own answer. Skip a question and the agent proceeds with a sensible default and says what it assumed.

The turn waits until you submit. Typing a message instead answers the questions with that message. An unanswered question also lands in your inbox, like a plan awaiting approval.

## AI-written PDF reports

Ask the assistant for a report, and it researches the project and returns a PDF in the chat. The report includes a cover, contents, sections, tables, charts, a data-sources appendix, and numbered references to the items it cites.

Every number in a table or chart must come from data the assistant retrieved in that conversation, so a figure it cannot trace is refused rather than printed. Re-rendering after feedback creates a new version linked to the previous one. A scheduled automation can produce a report on each run and list it in its finish notification.

## Ask the AI to fill or update a Word document

Attach a .docx or .dotx and ask the assistant to fill it in from the project or from what you tell it, or to bring stale values up to date. The assistant returns a new Word document you can download from the chat and leaves the original untouched. It fills placeholders, content controls, and mail merge fields, including in tables, headers, and footers, and keeps the existing formatting.

The edit's card lists every changed paragraph with its old and new text, and any placeholders still to fill.

## Address a comment with AI

Open comments on a branch, whether on items or in the branch discussion, offer **Address with AI**. The agent reads the thread, proposes a plan for you to approve, makes the change on that branch, and replies in the thread with what it did. The comment stays open for you to resolve. Available to editors when AI is enabled, and not offered on Base.

## Merge a branch that has sub-branches

A branch with live sub-branches can now be merged. The merge carries each sub-branch onto the branch it merges into, where it continues with its own changes intact, as **Update from parent** would. The review panel lists beforehand which sub-branches will be updated, and a failed update of one rolls the whole merge back. Automatic merging still waits while sub-branches exist.

## Improvements & Fixes

### Agent

- **Edit with AI is a normal chat.** Right-click → **Edit with AI** starts an ordinary assistant chat with the selected items attached. It uses your usual plan and auto-accept defaults, and appears in chat history as "Edit" followed by the item name.
- **Edited files at the end of a reply.** When a reply edited PDFs or workbooks, it ends with a card per file summarizing what changed, with **View changes** and **Download**. The side-by-side comparison also has a **Download** button.
- **PDFs from LaTeX.** The assistant and automation scripts can compile a self-contained LaTeX document into a PDF saved to the project's files.
- **Shorter impact analysis summaries.** An impact analysis closes with a summary card: a one-line verdict and up to three key findings, each with a suggested action and owner.
- **Focused answers.** Overviews and explanations stay focused on your question, with incidental requirement conflicts noted after the answer.
- **Large imports in chat.** Opening a chat whose agent changed thousands of items no longer freezes the page. **Keep All** and **Undo All** work on imports of any size.
- **Pauses include the question.** The assistant writes out the full question and its options before pausing, instead of a one-line summary.

### Automations

- **Script automations are always on.** Every workspace can create and run Python script automations, including branch checks, without a pre-release switch. Existing script branch checks now run on branch review and can block merging.
- **Document exports from scripts.** Scripts and the agent can read the tree a saved view shows under an item, link back to items and files, and save the HTML they build as a project file. HTML files open rendered in the file preview, where **Download as PDF** prints or saves them.

### Branching

- **Large workspaces.** Creating a branch or updating one from its parent no longer fails with an internal error when many recalculations are queued, and formula values keep updating.
- **Deleting or merging large branches.** Cleanup after a large branch is deleted or merged no longer holds up other branch operations.

### Diagrams

- **AI diagram layout.** Asking the assistant to auto-arrange a diagram no longer fails, and diagrams it creates are laid out as **Auto arrange** would draw them.

### Files

- **Sharper PDF previews.** PDF pages render at higher resolution and scroll as one document, with zoom controls in the footer. While editing a citation, select, move, resize, or draw its highlighted region on any cited page.
- **Attachment citations in tables.** Changing the pages or region an attachment cites from a preview opened in a table cell now saves.
- **Faster image thumbnails.** File fields load image thumbnails without downloading the full image first.

### Formulas

- **Use a spreadsheet cell in a field.** In the preview of an attached Excel or CSV file, click a cell and choose **Set an item's field from this cell...** or **Copy formula referencing this cell**. The field updates when a new version of the file is attached.
- **Item references.** An item reference in the formula editor no longer turns blank when you move the cursor after typing or pasting it.

### Import and Export

- **ReqIF export.** Every ReqIF export now runs on the server, so the large project mode checkbox is gone. Each scope's preview is always available, and item counts appear on the Mappings step. The download is always a `.reqifz` archive.

### Login

- **First admin invitations.** Invitation emails for a new hosted workspace's first admin link to the workspace's Flow address.

### Reader

- **Rich-text table ranges.** With several cells selected, the cell menu offers **Delete selected rows**, **Delete selected columns**, and **Clear cells**. A single cell's menu offers **Clear cell**.
- **Live collaboration retired.** Reader live collaboration (beta) no longer shares keystrokes or shows editor presence. Other sessions still receive saved edits, and contextual comments remain available.

### Table

- **Wrap item names.** With **Wrap columns** on, long item names show in full over several lines.

### Views

- **Private views from Settings.** **New private view** in **Settings → Views → My views** starts a blank personal view and opens its settings.
- **Private views in reviews.** The view picker on review and comparison pages lists your private views and those shared with you.

## API Changes

- **Remove users.** Admins can remove one user or many at once with an API key through the [Customer API](/api/reference). A bulk request reports any user it could not remove. Hosted MCP does not offer these actions.
- **Merging branches with sub-branches.** `GET branch/:id/merge-rebase-preview` lists the sub-branches a merge will update. `POST branch/:id/merge` accepts `expected_rebase_ids`, and the merge is refused if that set has changed.
- **Diagram layout.** Diagrams the Customer API creates are laid out as **Auto arrange** would draw them, instead of on a plain grid.
