## Find and undo a person's changes with AI

Ask the AI assistant what someone changed on a branch or on Base, optionally narrowed to certain fields, items, or a time range, and it lists their edits.

Ask it to undo some of them, such as their description edits, and it puts those fields back as they were. Anything someone else changed since is left alone and reported.

## Forms and secrets in AI chat

The agent can ask for structured data with a form card in the chat. An API key or password goes in a masked secret field. Flow stores it encrypted, and the agent uses it by name for one API host without ever seeing it. A key pasted into the composer is held, so you can save it as a secret instead of sending it.

## Improvements & Fixes

### Agent

- **Search results in chat.** Expanding a completed "Searched" step lists the matching items instead of reporting "Search failed".

### Branching

- **Merge conflicts on formula fields.** A formula's result no longer shows as a conflict when only its inputs differ, and **Keep parent** on a formula field adopts the parent's formula. Reverting a changed item that has a formula no longer fails on the review page.

### Data Model

- **Merging field options.** Legacy option values beginning with a bracket no longer prevent an option merge from completing.

### Integrations

- **Slack channel history.** Agents and automations can read message history from channels approved for their project. Admins configure read access separately from posting, and no channels are readable by default. Mentioning Flow in a thread gives it context from that discussion only.

### Review

- **Reverting cleared fields.** Reverting an item whose field was empty when the branch was created removes it from Changed items and no longer blocks the merge with a hidden conflict.

### Table

- **Tables on busy branches.** Tables on a branch where many items were created or placed at the top level no longer fail to load.

### Views

- **Save current view.** Save a private or shared view from the View structure card, and edit its structure, display options, filters, and sorting before saving.
