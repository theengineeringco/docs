## Personal Slack notifications

Organizations with Slack connected now send review assignments, review submissions, ready-for-review updates, and comment mentions as Flow bot DMs to users with matching Slack email addresses. Messages include review feedback, comment excerpts, and changed values when available.

When Slack is connected, **Preferences → Notifications** shows a Slack column with its own controls alongside Email and In-app.

## Share the path above an item

The share dialog's Link options add **Show path above**. Recipients also see the parents the shared item sits under, as a path only, never those parents' other children.

The path is shared as it stands when you create the share. Select **Update path above** on the share to refresh it after the item moves. Shares show only the item and what sits under it unless you turn this on.

## Scope users provisioned through SCIM

Under SCIM Provisioning, **Projects for provisioned users** lets new accounts start in specific projects instead of all of them. Each provider under SSO Roles' automatic user provisioning has its own project list. People who already have an account keep their current access.

**Groups that grant Member** lists the groups your identity provider sends. Viewers in a chosen group become Members, and return to Viewer when they leave every chosen group. Administrators, external users, and roles an administrator set by hand stay as they are.

## AI imports from Word documents and figures

The AI assistant can read the text of an attached or stored .docx file and create items from it. Table layout and images are not included, so export to PDF when those matter.

When the AI creates an item from a figure, diagram, or table in a PDF or image, it can place a picture of that region in the item's description, alongside the highlighted source attachment.

## Improvements & Fixes

### Agent

- **Live step results.** Each step of an AI reply shows what it found as soon as it finishes, such as search matches, counts, and items read, instead of a "Searching…" placeholder until the whole reply is done.

### Dashboards

- **Shared layouts.** Placing widgets side by side or in their own rows is saved with the dashboard, so everyone sees the same arrangement. Until a dashboard is next rearranged or gets a new widget, each person still sees the grouping their browser last saved.
- **Drill-down.** Opening a segment in a table keeps the dashboard view's own filters, so the table lists only the items the chart counted.

### Data Model

- **Item picker in the create dialog.** Expanding a nested item while picking upstream or downstream links no longer closes the picker. The expand arrow responds across the full row height, so a near miss no longer selects the item.

### Reader

- **Embedded views.** Clicking **Select View** before choosing an item no longer removes the view block from the document.
- **Documents with embedded views.** Exports no longer print a blank page. The view prints its root item and saved view, with a link that opens it in Flow.
- **PDF and image exports.** Uploaded images and diagrams finish loading before export, including for people reading through a share. Diagram items now export their diagram, and Word exports with uploaded images no longer fail for share recipients.
- **Less-than-or-equal shortcut.** Typing `<=` in rich text produces `≤`, matching `>=` → `≥`.

### Review

- **Large comparisons.** Changed items are no longer dropped between pages of results.
- **Relationship changes.** Unchanged links no longer appear as removed and re-added when comparing items.

### Search

- **Text filters.** Typing in a view's text filter no longer stutters. The filter applies when you pause typing, press Enter, or click away.

### Table

- **Bulk tag edits.** A multi-select tag held by only some selected items appears as a partial choice. Selecting it adds it to all, and selecting a shared tag removes it from all while preserving other tags.
