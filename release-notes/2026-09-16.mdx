## Personal skills and a personal FLOW.md

Each project's Skills page now has a Personal section for skills, skill folders, and a "My FLOW.md" document that only you see. Personal content layers on top of the project's shared skills and FLOW.md and only applies when you chat with the agent yourself.

Automations and scheduled runs continue to use the project's shared configuration, so personal guidance never affects work triggered on behalf of others.

## Qase TestOps integration

Admins can connect Qase from Integration settings. Once connected, the AI agent can search Qase test data and read verification results, mapped into Flow's Pass, Fail, and Inconclusive values, so Qase runs contribute to requirement verification alongside other test sources.

## Optional subscriber reviewers

Users and user groups named in an item's Subscribers field now appear as optional reviewers on a review. Their reviewer row is dimmed and identified as **Optional**, so they can weigh in without blocking a merge. When another reviewer source lists the same person or group as required, that requirement continues to apply.

## GPT-6 Astra and Terra for Auto

**GPT-6 Astra** is available for the most demanding agent work on commercial production, subject to organization model and residency settings. **GPT-5.6 Terra** now backs the Auto model choice on commercial production, and both commercial production and RVTech now serve Terra through Amazon Bedrock rather than the direct OpenAI API.

## Connect MCP clients through Flow sign-in

Connecting claude.ai or ChatGPT to Flow now opens the Flow app for an ordinary sign-in with your password or single sign-on, then asks you to approve the connection for your organization. Approval creates an API key named `MCP connection (<client>)` that the client uses from then on; revoke it from **Settings → API access** to disconnect.

Cognito's hosted sign-in pages have been closed at the same time, so no MCP flow reveals the identity providers a workspace supports. Existing MCP URLs and credentials keep working.

## Email notifications for comment replies

Replies in a thread you are part of, and comments on items you subscribe to, now trigger an email in addition to the in-app notification. Emails are on by default and have their own switch under **Settings → Preferences → Notifications**, so you can mute thread traffic while keeping emails for direct mentions.

## Fixes

- **Jira connections.** Admins can pick the correct Jira site when the Atlassian account has access to multiple sites, and reconnecting preserves the workspace's selected site.
- **Formula builder.** A rollup that names a missing data type or field now keeps the builder open with the server's reason next to the editor, and preserves the previously saved formula.
- **Verification rollups.** Verification formulas now include directly linked items of the chosen type in addition to descendants, so linked test results contribute to requirement verification.
- **Formulas.** Reading a field from an empty `latest`, `max`, `min`, or `coalesce` result now returns an empty value instead of an error. Formulas that explicitly check for `None` keep their behavior.
- **Default-field autocomplete.** The formula editor's default-field autocomplete works again.
- **Bulk editing owner or reviewers.** The people picker opens with everyone already assigned to the selection at the top, and clicking a reviewer brings the whole selection to the same state instead of flipping each item independently.
- **AI plan execution.** Accepting a plan with **Execute** is now standing authorization for every step it names, so the agent continues on its own instead of stopping to re-ask. A turn that ends with no changes and no reply closes normally with a visible notice.
- **AI chat items across branches.** A chat renders its item pills from the branch the agent is working on, so items the agent created no longer show as missing when you read the chat from Base or another branch. The changed-items drawer opens, lists, and undoes on that branch too.
- **AI conversation memory.** Condensed conversation history now includes action results and errors, helping the assistant tell completed work apart from failed attempts.
- **Impact analysis.** Opening the review tab no longer starts AI processing. Choose **Run impact analysis** to begin; existing results remain available when returning to the tab.
- **Agent chat opening.** Sending the first message from the new chat screen opens the conversation directly, and revisiting a past conversation no longer briefly shows the previous one.
- **Review automations.** Past runs clearly show when an automation is no longer configured as a branch review, and explain why it is excluded from **Re-run all**.
- **Navigator address bar.** Clicking a navigation entry updates the address bar once, so the link is shareable immediately and browser Back returns to the previous item in one step.
- **Drag hint.** Holding Cmd or Ctrl while dragging an item no longer changes the drop; a Cmd/Ctrl drop now behaves like an ordinary move. Alt still links the item under the target without moving it.

## Improvements

- **Formula recalculation across branches.** Matching formulas reuse their result across branches with identical inputs, so bulk updates trigger fewer repeated calculations.
- **Drag overlay.** A drag now names what the drop will do. Over another item, the card reads **Moving here** with **Press Alt to keep original link** beneath; holding Alt switches it to **Keeping original link**. Between two rows it reads **Reordering**.
- **Comment reply emails.** See [Email notifications for comment replies](#email-notifications-for-comment-replies).
- **Personal preferences shortcut.** The settings cog in the sidebar footer opens **Settings → Personal → Preferences** directly. Personal settings are now at the top of the settings sidebar.
- **Faster profile pictures.** Uploaded profile pictures are scaled so the shorter side is at most 256 pixels and stored as JPEG, so avatars across tables, comments, and the sidebar load faster. PNG, WebP, and GIF uploads are still accepted and animated GIFs remain animated at the reduced size.
- **Select all across the whole view.** The table's select-all checkbox now selects every item in the view rather than only the rows on screen.
