## Branch actions you confirm in AI chat

Ask Flow AI to delete branches, merge a branch, or rebase a branch onto another parent. The chat lists each branch and says which ones it cannot act on and why. Untick any branch, then press **Delete**, **Merge**, or **Rebase**, or **Cancel**.

You can also ask Flow AI to update a branch from its parent. Without conflicts, the chat shows what the update brings in, and you press **Update** or **Cancel**. With conflicts, the chat shows each conflict with a suggested version and the reason. Change any choice, then press **Apply**. Every action runs with your own permissions, and the agent does not run it for you.

## Flow Smart Links for Confluence

Flow item links can show their current titles in Confluence Cloud. After an Atlassian administrator installs the optional app, each viewer connects their Flow organizations by signing in and giving consent.

## Improvements & Fixes

### Agent

- **GitHub code search.** Flow AI can search file contents on a connected GitHub repository's default branch, read exact line ranges, and cite the matching file, commit, and lines.
- **Integration items in chat.** Jira and Linear issues, Confluence, Notion, Google, SharePoint, and AoDocs documents, Asana tasks, Teamcenter items, and GitHub pull requests appear as clickable references. Hover for details, or open them in their tool.
- **Long chats.** Long conversations open at their latest messages. Scrolling up loads older messages without losing your place.
- **Deleted links.** A link to a deleted branch, review, item, or agent shows its name marked Deleted. Deleted branches and items open the page where you can restore them, and you can restore a deleted item from its hover card.
- **Merged branches.** A branch named in a chat shows its name marked Merged after the merge, instead of "Unavailable branch", and opens the merge record.
- **Chat branch after a merge.** When a chat's branch is merged or deleted, the chat moves to the same branch as the page, and your next message runs there.
- **Pending AI changes.** Pending AI changes no longer block comparing branch changes or choosing a version for an added cross-link.

### Architecture

- **Dependency view.** Opening the view on an item with many cross-links frames that item instead of the middle of its linked items.

### Branching

- **Update from parent.** Fields and child orders the branch already shares with its parent, such as the same Jira issue link or the same formula and result, are no longer listed as incoming changes.

### Collaboration

- **Live discussions.** Comments added while an item is closed or your connection is interrupted appear when you reopen the item or reconnect.
- **Opening a comment.** Reply and **Open thread** in the Inbox and pop-ups, and comment links in AI chat, land on the item's Discussions tab or the review's Activity feed with the comment highlighted.

### Data Model

- **Tag options.** Merging an orphaned tag or stage value into a live option works when both have the same name.
- **Saving during data model edits.** When a save is refused because the data model is being changed, the message names the person, agent chat, or automation making the change and since when.

### Integrations

- **GitHub @flow comments.** Flow's own pull request comments no longer start another automation run when they mention @flow.
- **Refused post-backs.** A review comment, check run, merge request note, or commit status that GitHub or GitLab refuses shows as failed in project activity instead of sent.
- **Declined consent.** Declining access on a provider's consent screen returns you to that integration's settings page with a clear notice.
- **Repositories shared across workspaces.** When a repository is enabled in more than one workspace on the same GitHub installation, project Integrations activity shows the skipped delivery instead of automations stopping silently. Enabling a repository that another workspace already uses on that installation is refused with an explanation.

### Review

- **Reviewer lists.** Groups appear before people, with optional reviewers last. Group members start folded, and clicking a name shows why that person or group is reviewing.

### Search

- **Descending sort.** Rows with an empty value in the sorted column stay at the bottom when sorting in descending order.
- **Item search on large projects.** Searching on a branch of a very large project answers in well under a second. An identifier such as `REQ-1234` returns its exact match alone.

### Table

- **Select all in focus.** The header checkbox selects every item matching the current view, focus, and filters.

### Views

- **Field and column pickers.** **Add field** stays open so you can pick several fields at once. Empty lists show **No fields** or **No fields match your search**.

## API Changes

- **Automations over MCP.** MCP clients can create, edit, and delete automations. A new automation is saved turned off until someone turns it on in Flow, and the client receives a link to it. Turn off a running automation before changing its instructions, script, or triggers over MCP. See [MCP tools](/api/mcp/tools).
