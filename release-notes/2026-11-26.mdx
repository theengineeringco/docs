## Improvements & Fixes

### Permissions and Sharing

- **Filtered shares.** When an external writer creates an item in a filtered share, the item starts with the tag and people values the share requires. Recipients see the share's filters as read-only pills.

## API Changes

- **Comment feedback in the Customer API.** Read who reacted to a comment with each emoji, and follow reaction additions and removals in the project event stream.
