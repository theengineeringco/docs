## Review branch changes where you edit

Use **Show changed in branch** to compare current and previous values in tables while you keep editing. Created, updated, and reordered items are tagged, and Tree and Reader show change markers.

On a branch, an item's details panel marks it **Changed in branch** or **Created in branch** beside its ID. Click the marker on a changed item to see each changed field and relationship as before and after, compared with the version the branch started from. Revert any single field, relationship, or rich-text paragraph from its **Revert** button, and keep editing while you review.

## Merge rules in Reviews settings

Admins can define, in one place under **Settings → Reviews**, the rules a branch in any project must meet before it can be merged. Each rule has its own switch: require a minimum number of approvals, and require every changed item to be reviewed by someone named in its chosen user fields. Every approval counts, including the branch author's. The page also decides whether the normal procedure can be overridden with a recorded reason, and by whom.

The review page explains which rule is still unmet. **Require reviews on all branches**, **Dismiss approvals when new changes are pushed**, **Allow reviewer removal**, and **Let merges change locked items** move here from Organization settings and work as before. Existing organizations keep their current merge behavior, with every new rule off.

## Ask the AI agent to run an automation or apply a template

The agent can run an existing automation on the items you name, with your permissions. It runs on a new branch named after the automation, so nothing reaches your branch until you merge it, unless you ask it to stay on your branch. If the run needs something it can't find, the agent asks you in the chat. It reports the result with links to the branch and the run in Activity. Scheduled and event-triggered automations run immediately.

Ask it to apply a template and it confirms the template and items with you, then applies it on a new branch.

## Pin an item reference to a version

In a description, hover an item reference and pick a point in its history under **Version**. The reference then shows the item as it was at that point and is marked with a clock. Clicking it opens a read-only details panel for that version, with **View current** to open the item as it is now. Links in that panel open linked items as of the same point. You can also open a past version from an item's **History** tab with **View this version**.

## Improvements & Fixes

### Agent

- **Automation suggestions.** The assistant can suggest turning repeatable workflows into automations.

### Architecture

- **Architecture view loading** (beta). A large architecture opened for the first time appears fully laid out in one step, sooner.

### Automations

- **Activity per item.** A run's field edits group into one card per item, with field names, option names, units, and people shown as they are in the item's History.
- **Rerun checks after comments** (beta). A branch check's **Rerun after** setting declares which comment events make its last result stale. Checks saved before this release keep their current behavior.
- **Review automations.** **Re-run all** is available even when automations are up to date.

### Branching

- **Update from parent.** Formula values and review lists on large branch trees settle much sooner after an update.
- **Merging large branches.** Merges of branches with thousands of changed items no longer fail with "Timed out and was canceled".

### Data Model

- **Requirement target suggestions.** Typing a target such as "at least 5 kg" or "between 10 and 20 mm" suggests setting any of the item's number fields. The typed unit is saved as the number's own unit.

### Import and Export

- **Large PDFs import whole.** PDFs over 500 pages or 32 MB import as one run, with every page keeping its own number. The upload limit still applies. PDFs attached to Flow AI chat are no longer refused for size, and the chat can read selected pages without a full import.
- **Export preview.** The export dialog shows the first 30 rows beside its settings and updates as you change options. Drag a column header to reorder exported columns.
- **Spreadsheet import.** New items can be created with supplied Entity Numeric IDs while existing matches update.

### Integrations

- **Linear projects.** The assistant and script automations can file issues into a named Linear project, and refuse names that match nothing or more than one project. The assistant can list your Linear projects again and reports Linear's own error messages.

### Notifications

- **Automation run notifications.** You get an in-app notification when an automation you run by hand finishes, or when a scheduled or triggered run you own fails or changes something. Turn them off under **Settings → Preferences → Notifications**.
- **Threaded review notifications.** Review updates and their comments share a Slack thread and an email conversation.
- **More Slack and email updates.** Comment replies arrive as Slack DMs, and branch merges can notify you by email and Slack.

### Permissions and Sharing

- **Path above on existing shares.** **Settings → Shares** can add or remove the path above an existing share.
- **Shares across branches.** Links, mentions, reviews, comments, and edits respond faster on other branches a share covers.

### Reader

- **Item references while editing.** Clicking an item reference in rich text selects it and keeps its preview card open, with **See details** to open the item.

### Review

- **Review filters on large branches.** Filtering a branch review's changed items checks every change, so the match count is the branch's real total.

### Search

- **Changed-item filters.** Filtering for items changed on a branch is faster, including when combined with other conditions.
- **Find in view.** Formula-backed date cells highlight matching dates.
