## When to use a skill

Use a skill to apply a consistent method to different items or branches: reviewing an interface, checking evidence, or writing to a house style. Define the inputs, checks, and expected output. Use an [automation](/ai-automations/automations) to run it on a schedule or event.

## Create and use a skill

1. Open **Settings → AI → Skills**.
2. Select **New skill** under **Organizational Skills** or **Personal Skills**. Use **New folder** to group related skills.
3. Name the task and specify inputs, checks, permitted changes, and expected output. Select **Ask AI** in the toolbar to draft the instructions with the agent; its proposal appears in the field for you to accept or discard.
4. Save, then reopen the skill to check the instructions and generated description.
5. In chat, ask for the skill by name and reference the items to inspect.
6. Inspect the **Loaded skill** step to confirm which instructions ran, then check the findings against their sources.

You can also ask the agent to create or update a skill from chat. Review the result before relying on it.

## Example skills

Adapt these instructions to your project's fields and engineering rules.

### Review an interface

> Compare the selected interface with the two systems it connects. Check that each value it defines, with its units and limits, matches what each side states. List mismatches and missing values with item references. Do not edit data.

### Check verification coverage

> For the selected items, follow their verification links to test cases and results. Check that each test covers the stated behavior, operating conditions, and acceptance limits, and that its latest result passes. List uncovered items and mismatches with item references. Do not edit data.

### Write a requirement statement

> Rewrite the selected requirement as one clear "The system shall…" statement describing observable behavior and the conditions in which it applies. Preserve stated limits; flag missing acceptance criteria instead of inventing them. Return a proposed rewrite for review.

## Choose the scope

| Instructions | Available in |
| --- | --- |
| Organizational Skills and FLOW.md | Everyone's agent conversations in the project, and its automations |
| Personal Skills and My FLOW.md | Your conversations in this project, including agents you delegate to |

Personal instructions do not follow you to other projects. Automation runs use only organizational configuration, excluding Personal Skills and My FLOW.md. Changes to your personal skills and My FLOW.md are listed in **Settings → Personal → Personal Log**, which only you can see.

Personal and organizational skills can share a name; neither replaces the other. Specify the scope when invoking one.

Viewers can inspect skills but cannot create or edit them. When you create a **New project** from an existing project with **Skills** selected, Flow copies its organizational skills and folders, excluding personal skills. Check copied instructions for references to the original project.
