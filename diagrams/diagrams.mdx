A diagram explains part of your system the way you would sketch it: boundaries, connections, flows, and the reasoning behind them. Shapes and text are free drawing. Item cards are live: each shows an item's current name and the fields you choose, so the picture stays tied to the model while you arrange it however the explanation needs.

1. Create an item of the **Diagram** type, then open it from the sidebar or choose **Open diagram** from its context menu.
2. Draw with the toolbar at the bottom of the canvas: **Arrow**, **Text**, **Image**, and the shape picker, which also holds frames, swimlanes, and any [engineering symbols](/diagrams/engineering-symbols) the project offers.
3. Add item cards with **Entity** on the toolbar, by dragging items from the sidebar onto the canvas, or by double-clicking empty canvas and searching.
4. Select a card and use **Fields** to choose which values it shows and in what order, or **See Details** to open the item.
5. Select **Auto arrange** to lay out connected cards, or use the chevron beside it to arrange left to right or top to bottom. Adjust by hand afterward.

Changes save automatically. The diagram menu at the top left holds Edit, View, **Import**, **Export**, and **Preferences** such as **Show grid** and **Always snap**.

## Decide which gestures change the model

Most drawing changes only the diagram. A few gestures can also change Flow's relationships:

- **Drawing a connector between two cards** offers **Create a link in Flow**, **Connect via…**, or **Create basic arrow**.
- **Nesting a card inside another, or moving it out**, asks whether to add, move, or remove the matching link in Flow.

Check both items and the direction before you confirm. Dismissing the prompt keeps the drawing without changing the model. Placing an item on a wire with **Allocate entity…** changes the drawing only, never the item's links.

If an item is deleted elsewhere, its card stays on the diagram, marked as deleted. Update the drawing yourself, or use an [architecture view](/diagrams/architecture-views) for a breakdown that follows the model automatically.

## Ask the agent to draw

Ask the agent to draw a diagram from items in the project, or from a schematic, P&ID, or wiring sheet you attach. It can use every shape in the picker, the project's enabled symbol libraries, and the fields you want shown on each card. Where a line on a schematic forks, it draws a junction so each branch reaches the component it runs to. Select **Open diagram** on the preview in the chat to review and edit the result.

## When you cannot edit

A diagram is read-only on a protected branch, on a branch restricted to other editor groups, at a locked stage, or with read-only access. On a protected branch, select **Create a branch** to make changes. You can still select, pan, zoom, copy, and [export](/diagrams/importing-exporting-diagrams).
