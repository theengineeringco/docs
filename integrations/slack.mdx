Connect Slack so your team can ask Flow about the system from the threads where the work is discussed. Connecting the workspace, reading channels, posting messages, and project access are separate settings.

## Connect Slack

An administrator sets up the connection.

<VisualPlaceholder kind="Screenshot" title="Slack settings: connect options, Channel history access, write-back + Allowed channels, Projects" />

1. Open **Settings → Administration → Integrations → Slack**.
2. Choose **Flow's Slack app** and select **Add to Slack**. Slack asks a workspace admin to approve Flow's permissions, then returns you to Flow.
3. To use your own app instead, choose **Your own Slack app**: create an app from Flow's manifest, install it to your workspace, then paste its **Bot User OAuth Token** and **Signing secret**.
4. Under **Projects**, turn on each Flow project that should be available in Slack.

## Use Flow from Slack

<VisualPlaceholder kind="Screenshot" title="/flow settings modal in Slack (project, branch, fork-a-branch option)" />

1. Run `/flow` in Slack. The first time, follow the link to connect your Slack account to Flow and select **Confirm account link**.
2. Run `/flow` again to pick the project and branch your chats run on, and whether each new Slack chat forks a fresh branch. These settings are yours alone.
3. Mention @Flow in a thread and keep follow-ups in the same thread.

Linking your account does not grant you access to any project you cannot already open in Flow. Unlink it from the Slack settings page with **Unlink my Slack account**.

## Control reading and posting

| Setting | What it controls |
| --- | --- |
| **Channel history access** | Channels that agents and automations in a project may browse. Mentioning @Flow in a thread always lets the agent read that thread |
| **Enable Slack write-back** | Whether the agent may send messages as the Slack bot |
| **Allowed channels** | The only channels the agent posts to and the people it may message directly |

Invite Flow to a channel before it can post there. Private channels and attachments need extra Slack permissions; for your own app, add the missing scopes and reinstall it.

Select **View activity** to check deliveries and actions. Personal Slack notifications are set in **Settings → Personal → Notifications** and do not give agents permission to post.
