Markdown export saves a snapshot of the Reader document for a documentation repository or text editor. Headings, text, lists, tables, and references follow the document as Reader shows it.

## Export

<VisualPlaceholder kind="Screenshot" title="Markdown export">
  Reader with More actions → Export as open, showing Markdown and Markdown + Assets.
</VisualPlaceholder>

1. Open the branch and view you want, then switch to **Reader**.
2. Focus the part of the hierarchy you need, and check item order, fields, and embedded content.
3. Choose **More actions → Export as → Markdown** for a single `.md` file, or **Markdown + Assets** for a ZIP archive.
4. Unzip the archive and keep its files together, then check tables and images in your editor.

A plain Markdown file embeds diagram images in the file itself, which some editors and previews do not display. **Markdown + Assets** saves diagram images as separate files that the Markdown links to. Other images and links are not packaged, so check them separately.

Editing the file does not change Flow; to update items from a file, use [CSV](/importing-exporting/csv) or [Excel](/importing-exporting/excel).
