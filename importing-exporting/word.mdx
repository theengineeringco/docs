Word export creates an editable `.docx` snapshot of the Reader document, for reviews and handoffs outside Flow. Comments and edits made in the file do not flow back; apply them in Flow.

## Export

1. Open the branch and view you want, then switch to **Reader**.
2. Focus the part of the hierarchy you need, and check headings, fields, and embedded content.
3. Choose **More actions → Export as → Word**.
4. Open the file in Word and check page breaks, wide tables, and images.

Note the branch and export date when you hand the file on. For a fixed reading copy, use [PDF](/importing-exporting/pdf).

## Give the agent a Word file

Attach a `.docx` to an agent conversation and ask about a specific section. To turn its content into items, name the item types, the fields to fill, and where the items belong. Check the results on your working branch against the source.

The agent can also fill in or update a Word document. Attach a `.docx` or `.dotx` and ask it to fill placeholders from the project, or to bring stale values up to date. It returns a new file and leaves the original untouched.

The edit card lists what changed and anything still to fill. Select **View changes** to compare the original and edited documents side by side, with removed text in red and added text in green, then **Download** the new file.

A Word file has no identity to match existing items. For repeatable updates, use [CSV](/importing-exporting/csv), [Excel](/importing-exporting/excel), or [ReqIF](/importing-exporting/reqif).
