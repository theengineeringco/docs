Export the Reader document as a PDF for a fixed reading copy, or give the agent a source PDF to answer questions about it or turn its content into items.

## Export a PDF

<VisualPlaceholder kind="Screenshot" title="Saving a PDF">
  The browser print dialog opened by Export as → PDF from Reader, with Save as PDF selected as the destination.
</VisualPlaceholder>

1. Open the branch and view you want, switch to **Reader**, and check scope, fields, and embedded content.
2. Choose **More actions → Export as → PDF**.
3. In your browser's print dialog, choose to save as PDF. Check margins, background graphics, and headers and footers, then save.
4. Open the saved file and check page breaks, wide tables, and diagram labels.

Your browser controls the file name and page layout.

## Read and extract from a PDF

1. Attach the PDF to an agent conversation by dropping it into the message box.
2. Name the pages and the question. The agent reads a long document a few pages at a time.
3. To create items, name the item types, the fields to fill, and where the items belong.
4. Check the new items and links on your working branch. Compare values from tables and figures with the source pages, especially units, limits, and conditions.

Keep the source file as evidence. Flow cannot read a PDF that needs a password to open; attach an unrestricted copy.
