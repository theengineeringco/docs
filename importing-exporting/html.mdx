HTML export saves the Reader document as a single web page you can hand to another publishing workflow. It does not publish anything or change who can see the content in Flow.

<VisualPlaceholder kind="Screenshot" title="Exported HTML open in a browser" />

## Export

1. Open the branch and view you want, then switch to **Reader**.
2. Focus the part of the hierarchy you need, and check item order, fields, and embedded content.
3. Choose **More actions → Export as → HTML**.
4. Open the file in a browser or your publishing system, and check headings, tables, and diagrams.

The file loads its stylesheets and fonts from the web. Before you treat it as an offline copy, open it without a network connection and check how it looks.

Anyone with the file can read its text, whatever their access in Flow. Editing the file does not change Flow; to update items from a file, use [CSV](/importing-exporting/csv) or [Excel](/importing-exporting/excel).
