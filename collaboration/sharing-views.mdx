A saved view gives everyone the same way to look at the same records: the systems breakdown, the verification thread, the open risks. Keep a private view for your own arrangement and a shared view for a project default. [The systems graph](/core-concepts/the-systems-graph) explains how views relate to the data.

## Save a view

<VisualPlaceholder kind="Screenshot" title="View structure panel and Save as new view dialog" />

1. Set up the view: its structure, relationships, filters, displayed fields, and mode.
2. Open **View structure** beside the view selector and choose **Save as new view**.
3. Enter a **Name** and choose a **View type**: **Private view** or **Shared view**.

New views are private by default. Only admins can create shared views.

Changing filters or structure does not change the saved view. In **View structure**, **Reset to view defaults** discards your changes, and **Update view defaults** saves them into the view. Anyone can update their own private view; only admins can update a shared one.

## Copy a link

1. Open **Share**.
2. Pick one item, one branch, and one saved view.
3. Choose **Copy link**.

The link opens that destination with the recipient's existing access; it grants nothing new. A private view stays personal, so use a shared view when others should see the same configuration. If someone cannot open the link, check their project membership, the branch, and their permissions.

To give someone access they do not already have, follow [Sharing](/collaboration/sharing).
