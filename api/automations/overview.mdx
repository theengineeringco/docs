An automation combines instructions with a trigger. Create and manage it in Flow or through the Customer API, send an event, and use the API to track the resulting runs.

## Choose a trigger

| Trigger | Use it for |
| --- | --- |
| Custom webhook | Events from your own tools, identified by a webhook name. |
| API endpoint | Automations configured with the `endpoint` source. |
| Connected app | Events from an app connected to Flow, such as GitHub or Slack. |
| Branch review | Checks and actions associated with a Flow branch review. |

Integrations connect external apps to Flow. Automations define the work Flow runs when an event arrives.

## Set up and run

1. List or create the project's automations with `GET` or `POST /project/{projectId}/automations`.
1. [Set up a webhook automation](/api/automations/webhooks): configure its instructions and name, then send a JSON event.
2. [Trigger and poll automations](/api/examples/automations): start runs asynchronously, store their IDs, and read the results.
3. Use the [endpoint reference](/api/reference) for complete request and response schemas.

A trigger request matches automations by source. One request can start multiple runs. Include `project_id` to target the intended project, and track each returned `agent_id` separately.

## Manage project automations

Use `GET /project/{projectId}/automations` to list automations, or add an automation ID to read, update, or delete one. `POST /project/{projectId}/automations` creates an automation; `PATCH /project/{projectId}/automations/{automationId}` changes only the fields you send. A supplied `trigger` replaces the whole trigger, and `null` makes the automation manual.

An automation runs with the permissions of the person who last saved what it runs. When changing another person's automation in a way that affects its work or trigger, send `runAsMe: true` to confirm that it will run as you; otherwise the update returns `409`. Renaming, disabling, or turning off admin tools keeps the current writer. An API key cannot enable `allowAdminTools`. Script mode requires the automation scripts beta.
