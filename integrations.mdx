Bring context from your team's tools into Flow. Integrations connect engineering data, documents, code, and conversations so you can work with them alongside your systems graph.

## Get started

Choose an application from the sidebar to find its setup guide. Each guide covers capabilities, permissions, connection steps, and verification. **Settings → Integrations** in Flow shows the connections available to your workspace.

Some connections require additional configuration or are available only on supported deployments. Check the guide's prerequisites before you begin.

## Choose the access you need

Some integrations use shared workspace credentials; others require each person to sign in. A default project, folder, or search filter is not always an access boundary. Each guide explains which account provides access and how to limit its scope.

Where an integration supports write-back, both the external account and Flow's settings must permit the action. External changes take effect in the connected tool and are not undone by reverting a Flow branch.

## Connect custom tools

Use [Custom MCP](/integrations/custom-mcp) to connect an external MCP server and choose the tools Flow AI can use.

To use Flow's tools from an external AI client, see [Flow MCP](/api/mcp/overview). To build an integration against Flow's REST API, start with the [API quickstart](/api/quickstart).

Integration updates are included in the [release notes](/release-notes).
