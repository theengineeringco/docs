Connect the tools your team uses to give Flow context from engineering work, documents, code, and conversations. Each guide explains what the integration can do, who can configure it, how to connect it, and how to verify access.

Open **Settings → Integrations** in Flow to see the connections available to your workspace. Some connections require additional configuration or are available only on supported deployments; the individual guides describe those requirements.

## Choose the access you need

Connections differ in how they grant access. Some use shared workspace credentials; others require each person to sign in. A default project, folder, or search filter is not always an access boundary. Check the guide before choosing a scope.

Where an integration supports write-back, both the external account and Flow's settings must permit the action. External changes take effect in the connected tool and are not undone by reverting a Flow branch.

See [Release Notes](/release-notes) for changes to integration capabilities.
